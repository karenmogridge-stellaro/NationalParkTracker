# ParkAtlas Frontend

React + Vite dashboard for tracking national park adventures.

## Setup

Install Node.js 18+, then:

```bash
cd frontend
npm install
npm run dev
```

Opens on [http://localhost:3001](http://localhost:3001)

## Features

- 🏞️ Dashboard with park passport stats
- 🗺️ Park directory with filterable search
- 🥾 Hike logging and tracking
- ⛺ Camping trip logs
- 🦌 Wildlife sighting gallery
- 📊 Adventure statistics

## Stack

- React 18
- Vite
- Tailwind CSS
- Recharts
- Axios
