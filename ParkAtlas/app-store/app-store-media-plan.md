# ParkAtlas App Store Media Plan

## 1) Required Assets

### App previews (video)
- Optional, but recommended.
- Up to 3 previews per device size.
- Length per preview: 15 to 30 seconds.
- Use only in-app footage.

### Screenshots
- Required for at least one iPhone size.
- Recommended: provide for iPhone 6.9-inch and iPhone 6.5-inch.
- Optional: iPad screenshots if listing iPad support.

## 2) Screenshot Size Targets

Use portrait orientation throughout for consistency.

### iPhone 6.9-inch (required if targeting newest Pro Max class)
- 1320 x 2868 px

### iPhone 6.5-inch
- 1242 x 2688 px

### iPad Pro 13-inch (optional)
- 2064 x 2752 px

## 3) ParkAtlas Shot Order (recommended)

Use this exact sequence for conversion-focused listing flow.

1. Home dashboard
- Headline: Track all 63 national parks
- Show stats cards and map summary

2. Parks map with markers
- Headline: Explore parks on an interactive map
- Show visited vs to-visit markers and selected park card

3. Checklist manager
- Headline: Build your to-visit checklist
- Show To Visit and Visited segmented states

4. Log outing sheet
- Headline: Log outings in seconds
- Show park picker and quick-add details

5. Activity/feed history
- Headline: Keep every outing organized
- Show combined activity timeline

6. Settings + feedback
- Headline: Secure account and send feedback
- Show Face ID lock and feedback modal

## 4) App Preview Storyboard (30s)

### Preview 1: Explore + Plan
- 0-3s: Open app, land on Home
- 3-10s: Pan/zoom map and select a park
- 10-18s: Add to checklist, switch To Visit/Visited
- 18-24s: Open park detail page
- 24-30s: End on map + checklist summary

### Preview 2: Log + Review
- 0-6s: Open Log Outing sheet
- 6-15s: Pick park, date, distance, rating
- 15-22s: Save outing and show updated stats
- 22-30s: Open Parks stat breakdown and edit entry

### Preview 3: Account + Trust
- 0-8s: Open settings and Face ID lock toggle
- 8-18s: Open Send Feedback and draft message
- 18-30s: Return to dashboard with polished summary view

## 5) Copy Guidelines
- Keep screenshot headline text under 38 characters.
- Keep subtitle text under 70 characters.
- Avoid mentioning unsupported features.
- Keep all metadata language consistent with in-app labels.

## 6) Acceptance Checklist
- Screenshots match real shipped UI.
- No placeholder data, no lorem ipsum.
- No references to Android-only functionality.
- Status bar time/carrier are clean and consistent.
- Privacy-sensitive account info is anonymized.
