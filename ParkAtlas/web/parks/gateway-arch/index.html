Gateway Arch

The iconic 630-foot Gateway Arch on the Mississippi riverfront celebrates westward expansion.

🥾 3+ trails 🎟️ Free ⛺ No campgrounds ☀️ Year-round 📅 Open year-round

Trails

Gateway Arch has roughly 3 named trails. Log the one you hiked in the app — or just the park if you're not sure.

Camping

There are no NPS campgrounds inside the park. Lodging and private campgrounds are typically available nearby.

Find places to stay near Gateway Arch →

Best time to visit

Peak season: Year-round. The park is open year-round, though some roads and facilities close or run reduced hours in winter.

Getting there

Nearest city: St. Louis, MO. Park center: 38.630°, -90.190°.
